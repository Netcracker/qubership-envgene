# План реализации PLACE-8

> **Для агентов:** использовать superpowers:subagent-driven-development или superpowers:executing-plans. Подробные шаги и код проверок: [английский план](../2026-09-11-place8.md).

**Цель:** сообщать о пустых сущностях без видимых привязок для ручной проверки.

**Архитектура:** расширить индекс и обнаружение профилей, credentials и их привязок.
Разрешать физические пути с существующим алгоритмом ParameterSet и приоритетными
каталогами профилей/credentials; проверять структуру отдельным правилом PLACE-8.

**Стек:** Python 3.12, ruamel.yaml, pytest, существующий CLI на Click.

**Спецификация:** [согласованный дизайн](../../specs/ru/2026-09-11-place8-design.md).

## Общие ограничения

- Только согласованная проверка пустых сущностей, без эвристик размера и назначения.
- Пустые подключённые и непустые файлы не дают замечания; пустые неподключённые — Information / Review.
- Привязки из шаблонов не проверяются. Точные тексты и алгоритм определены спецификацией.
- Новые поля имеют пустые значения по умолчанию; без новых зависимостей и CLI-опций.
- Только синтетические примеры. Без сети, публикации, генерации и изменений реальных репозиториев.
- Работа в существующей ветке `feat/place8`; посторонние файлы сохраняются.
