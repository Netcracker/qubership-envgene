# План: PLACE-2

Английская копия (по ней пишут код): [../2026-09-02-place2.md](../2026-09-02-place2.md)

**Что получим:** `check` сначала печатает PLACE-1, потом PLACE-2.

**Идея:** ядро не трогаем. Добавляем правило «сверху скопировали то, что уже есть снизу», клеим его в отчёт после PLACE-1.

## Четыре задачи

### 1. Само правило

Новый файл `rules/place2.py` и тесты:

- env скопировал `LOG_LEVEL` с кластера → один warning
- `REPLICA_COUNT` другой → тишина
- ключа снизу нет → тишина
- кластер скопировал репозиторий → один warning
- два env смотрят на один кластерный повтор → всё равно один warning

Точный код — в английской копии плана.

### 2. Отчёт и `check`

В консоли всегда два заголовка:

```
PLACE-1
…

PLACE-2
…
```

Если правило молчит — `No findings` под его заголовком. Код выхода не меняем.

Нужно поправить старые тесты отчёта и CLI: раньше пустой прогон печатал только PLACE-1.

### 3. Живые деревья

`testdata/place2/not-ok` — кластер и env оба пишут `LOG_LEVEL: info`.  
`testdata/place2/ok` — в env только другое значение (`REPLICA_COUNT: 3`).
