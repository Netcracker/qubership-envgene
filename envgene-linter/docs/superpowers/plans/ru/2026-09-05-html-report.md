# План: HTML-отчёт

Английская копия (по ней пишут код): [../2026-09-05-html-report.md](../2026-09-05-html-report.md)

**Что получим:** `check --html` печатает консоль и пишет `envgene-linter-report.html` в корень instance-репо.

**Идея:** ядро и консоль не трогаем. Новый renderer собирает страницу из тех же `Finding`. CLI только пишет файл.

## Две задачи

### 1. Страница

Новый `html_report.py` и тесты:

- два finding в одном файле → один заголовок, две карточки, сначала PLACE-1
- два файла → заголовки по пути
- пусто → `No findings` и нули в итоге
- `<` в тексте → `&lt;`
- нет `<script`

### 2. Флаг `--html`

В `cli.py`: сначала консоль, потом запись. Успех — строка в stderr. Не записали — stderr и выход 2. Без флага файла нет. Stdout тот же, что без `--html`.
