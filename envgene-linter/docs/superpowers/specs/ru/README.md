# Спецификации

Здесь собраны 17 спецификаций разработки. У каждой есть английская и русская версия.

## Как читать

1. Сначала прочитайте [общее ограничение подключённых сущностей](2026-09-11-connected-only-design.md). Оно распространяется на все правила, включая NAME-3, и заменяет прежний отбор файлов.
2. Затем откройте спецификацию нужного правила. Примечание в начале исторического документа объясняет, какие решения заменены. Остальной текст сохраняет контекст того этапа разработки.
3. Для пошагового описания текущего поведения используйте документы [алгоритмов](../../../algorithms/ru/connections.md) и ссылки на правила в таблице ниже.
4. HTML-спеки одного дня читаются в порядке: исходный дизайн → переработка → улучшение удобства. Более поздний этап заменяет только явно изменённые требования.

Спецификации фиксируют требования и историю решений. Алгоритмы описывают текущую реализацию. Редактура формулировок не добавляет новые проверки.
