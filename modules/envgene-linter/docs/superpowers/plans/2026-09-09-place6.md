# PLACE-6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Report PLACE-6 when `envSpecificE2EParamsets` has a map key other than `cloud` (case-insensitive); TYPE Warning, ACTION Fix. One finding per environment + bad target.

**Architecture:** `rules/place6.py` reads `env.bound_targets(Category.E2E)` from `RepoIndex` and reloads `env_definition.yml` only for the target-key position. No `compute`. Catalog, `RULE_ORDER`, and engine grow by one rule. PLACE-5 is not in the catalog.

**Tech Stack:** Python 3.12+, pytest, existing `RepoIndex` / `RepoBuilder`.

**Spec (English):** `docs/superpowers/specs/2026-09-09-place6-design.md`  
**Spec (Russian):** `docs/superpowers/specs/ru/2026-09-09-place6-design.md`

## Global Constraints

- Do not edit `env_definition`. No autofix.
- Do not call `compute` / Effective Set for PLACE-6.
- Do not change discovery.
- Only `envSpecificE2EParamsets`. Do not check deploy/technical targets. Do not match against `Namespaces/`.
- A target is Cloud iff `target.lower() == "cloud"`. Any other key is a finding.
- One finding per environment + bad target (not per stem under that target).
- Warning / Fix. Severity `warning`.
- Message: `{target} is not the Cloud; pipeline ParameterSets must bind under envSpecificE2EParamsets.cloud.`
- Hint: `Move the envSpecificE2EParamsets.{target} list to cloud.`
- `key` is the target as written. `scope` is `"<cluster>/<env>"`.
- Path: `{env.path}/Inventory/env_definition.yml`. Position: `("envTemplate", "envSpecificE2EParamsets", target)`. `YamlReadError` → skip that environment.
- Catalog description: `Pipeline ParameterSets bind to the Cloud`.
- `RULE_ORDER = ("PLACE-1", "PLACE-2", "PLACE-3", "PLACE-4", "PLACE-6", "NAME-1", "NAME-2", "NAME-3", "NAME-4")`.
- A fixture with only `envSpecificParamsets.cloud` (no e2e block) is an empty PLACE-6 block.
- Do not implement PLACE-5 or PLACE-7. Do not change PLACE-1…PLACE-4 or NAME-* behavior.
- Prefer `.venv/bin/python -m pytest` (`pyproject.toml` already has `pythonpath = ["src"]`).
- Work in an isolated git worktree (not on `master`). Include the PLACE-6 specs on the branch if still uncommitted.

```python
"""PLACE-6: Pipeline ParameterSets bind to the Cloud."""

from __future__ import annotations

from ..discovery import ENV_DEFINITION_FILE, INVENTORY_DIR
from ..model import Category, Finding, Location, RepoIndex, Severity
from ..rulemeta import RULES
from ..yamlio import LoadedYaml, YamlReadError, load

_MESSAGE = (
    "{target} is not the Cloud; pipeline ParameterSets must bind under "
    "envSpecificE2EParamsets.cloud."
)
_HINT = "Move the envSpecificE2EParamsets.{target} list to cloud."


def check(index: RepoIndex) -> list[Finding]:
    findings: list[Finding] = []
    for env in index.environments:
        path = env.path / INVENTORY_DIR / ENV_DEFINITION_FILE
        loaded: LoadedYaml | None = None
        for target in env.bound_targets(Category.E2E):
            if target.lower() == "cloud":
                continue
            if loaded is None:
                try:
                    loaded = load(path)
                except YamlReadError:
                    break
            line, column = loaded.position(
                ("envTemplate", "envSpecificE2EParamsets", target)
            )
            findings.append(_finding(env.cluster, env.name, path, target, line, column))
    findings.sort(key=lambda item: (item.path.as_posix(), item.key, item.line))
    return findings


def _finding(
    cluster: str,
    env_name: str,
    path,
    target: str,
    line: int,
    column: int,
) -> Finding:
    meta = RULES["PLACE-6"]
    return Finding(
        rule="PLACE-6",
        severity=Severity.WARNING,
        path=path,
        line=line,
        column=column,
        issue_type=meta.default_issue_type,
        action=meta.default_action,
        key=target,
        scope=f"{cluster}/{env_name}",
        message=_MESSAGE.format(target=target),
        hint=_HINT.format(target=target),
        related=(),
        locations=(Location(path, line, column),),
    )
```

Russian copy (for the reader): [`ru/place6.md`](./ru/place6.md).

**PLACE-6 (MUST):** a pipeline ParameterSet associates to the Cloud only. The

Path: `{env.path}/Inventory/env_definition.yml`. Load for

that environment.
