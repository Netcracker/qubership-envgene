# PLACE-12 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Report shared-template-default candidates from at least two local environments as PLACE-12 Review.
One cluster is sufficient, as requested in the November 5, 2026 scope update.

**Architecture:** Capture the literal template identity during discovery and reuse the existing connected Effective Set.
A dedicated rule checks complete template groups, scope agreement, independent provenance, and exclusions.
Existing metadata, diagnostics, and report paths expose the findings without a schema change.

**Tech Stack:** Python 3.12, ruamel.yaml, pytest, and the existing EnvGene Linter modules.

**Spec:** [PLACE-12 design](/modules/envgene-linter/docs/superpowers/specs/2026-11-05-place12-design.md).

## Global constraints

- All findings use Information / Review. No automatic edits or confirmed-promotion claims.
- Require at least two applicable environments. They may belong to one cluster or several clusters.
- Preserve category, target, application, typed value equality, and existing source-staging semantics.
- Require at least two distinct physical source entries. Aliases or repeated consumers of one entry add no support.
- Resolve physical source ownership and passport completeness before using key catalogs as evidence.
- Python requirement remains `~=3.12`. Runtime dependencies and the package version remain unchanged.
- No new flags, network access, template rendering, or cross-repository aggregation.
- Documentation and synthetic examples are English. Real input data and trial outputs stay outside Git and PyPI.
- Keep commits and pushes for an explicit user request. Preserve normal Git hooks.

## Review focus

- A missing or dynamic template identity must not join an apparently matching literal group: Task 1 tests this.
- A third missing or conflicting consumer must block a path even when two others agree: Task 2 tests this.
- Aliased cluster directories and source entries must not manufacture independent support: Task 2 tests this.
- Secrets, passport keys, unresolved expressions, and identifiers must not receive promotion advice: Task 2 tests this.
- Incomplete, disabled, and template-only execution must retain truthful report states: Task 3 tests this.
