**Goal:** Report a ParameterSet reference bound to multiple categories within one environment.

**Architecture:** `rules/place7.py` consumes existing `RepoIndex` bindings and reloads environment definitions for source positions. The engine, catalog, and existing report renderers expose one finding per conflicting name and environment. Documentation and fixtures describe the same contract.

**Tech Stack:** Python >=3.12, Click, ruamel.yaml, pytest; existing dependencies only.

## Global Constraints

- Approved specification: `docs/superpowers/specs/2026-09-11-place7-design.md`.
- Categories are not aggregated across environments.
- Names are compared exactly as stored in `RepoIndex`, without case folding or filename-suffix normalization.
- Category order is `deploy`, `e2e`, `technical`.
- One finding per environment and conflicting reference name; all binding occurrences are locations.
- `severity`: `Severity.WARNING`; `issue_type`: `Warning`; `action`: `Fix`.
- Message: `ParameterSet {name!r} is bound to multiple categories: {categories}.`
- Hint: `Use a separate ParameterSet for each category, even when the parameter values are identical.`
- Catalog description: `One category per ParameterSet`.
- PLACE-7 follows PLACE-6 and precedes NAME-1; ten rules in the console.
- Findings retain exit code 0. No autofix or new CLI options are introduced.
- No changes to discovery, yamlio, Effective Set, or existing rule behavior.
- Preserve existing untracked files. Work on `feat/place7` in the current checkout.

```python
from collections import defaultdict

from ..discovery import ENV_DEFINITION_FILE, INVENTORY_DIR
from ..model import Category, Finding, Location, RepoIndex, Severity
from ..rulemeta import RULES
from ..yamlio import YamlReadError, load


def check(index: RepoIndex) -> list[Finding]:
    findings = []
    for env in index.environments:
        categories = defaultdict(set)
        paths = defaultdict(list)
        for category in Category:
            for target, names in env.bound_targets(category).items():
                for position, name in enumerate(names):
                    categories[name].add(category)
                    paths[name].append((
                        "envTemplate", category.binding_field, target, position,
                    ))
        conflicts = {name: used for name, used in categories.items() if len(used) > 1}
        if not conflicts:
            continue
        path = env.path / INVENTORY_DIR / ENV_DEFINITION_FILE
        try:
            loaded = load(path)
        except YamlReadError:
            continue
        meta = RULES["PLACE-7"]
        for name, used in conflicts.items():
            positions = sorted({loaded.position(p) for p in paths[name]})
            locations = tuple(Location(path, line, column) for line, column in positions)
            primary = locations[0]
            label = ", ".join(c.value for c in Category if c in used)
            findings.append(Finding(
                rule="PLACE-7", severity=Severity.WARNING,
                issue_type=meta.default_issue_type, action=meta.default_action,
                path=path, line=primary.line, column=primary.column,
                key=name, scope=env.full_name, related=(), locations=locations,
                message=f"ParameterSet {name!r} is bound to multiple categories: {label}.",
                hint="Use a separate ParameterSet for each category, even when the parameter values are identical.",
            ))
    findings.sort(key=lambda item: (item.path.as_posix(), item.key, item.line))
    return findings
```
