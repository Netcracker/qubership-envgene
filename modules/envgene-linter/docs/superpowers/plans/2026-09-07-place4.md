**Goal:** Report PLACE-4 when a bound ParameterSet contains a Cloud Passport contract key from `TABLE`; TYPE Warning, ACTION Fix. Slim PLACE-3 to misplaced passport files only.

**Architecture:** `rules/place4.py` reads `RepoIndex` only — bound stems from `env.bindings`, keys from `leaves(parameters)` matched against `TABLE` in `passport.py`. No `compute`. PLACE-3 drops `_repository_keys` and `_env_agreement`. Catalog, `RULE_ORDER`, and engine grow by one rule.

**Tech Stack:** Python 3.12+, pytest, existing `RepoIndex` / `RepoBuilder`.

**Spec (English):** `docs/superpowers/specs/2026-09-07-place4-design.md`  
**Spec (Russian):** `docs/superpowers/specs/ru/2026-09-07-place4-design.md`

## Global Constraints

- Do not edit YAML or move keys. No autofix.
- Do not call `compute` / Effective Set for PLACE-4.
- Do not merge the passport into the Effective Set.
- Keys: `TABLE` only (`src/envgene_linter/passport.py`). Custom keys that appear only in a passport file are not PLACE-4.
- Bound ParameterSets only (stem listed in at least one `envSpecific*`). Unbound files are silent.
- Site, cluster, and environment layers all count. Deduplicate by resolved path.
- Match the **top key** of `leaves(parameters)`. One finding per file + top key.
- Jinja: try `load`; `YamlReadError` → skip. Do not change discovery.
- Warning / Fix. Severity `warning`.
- Message: `{key} is a Cloud Passport contract key; do not store it in a ParameterSet.`
- Hint: `Move {key} to the cluster cloud-passport, or to this environment's cloud-passport if the value is an override.`
- Catalog description: `Cloud Passport keys do not belong in ParameterSets`.
- `RULE_ORDER = ("PLACE-1", "PLACE-2", "PLACE-3", "PLACE-4", "NAME-1", "NAME-2", "NAME-3", "NAME-4")`.
- A fixture that binds `env-params` with no table keys is still an empty PLACE-4 block.
- PLACE-3 keeps only `_misplaced_files`. Keep `check(index, full, lower, site, catalogs)` signature so the engine call site stays valid until Task 4; unused args are fine.
- Do not change the PLACE-1 catalog skip (`Catalogs` = table ∪ flattened passport keys).
- Do not change PLACE-3 catalog description.
- Prefer `.venv/bin/python -m pytest` (`pyproject.toml` already has `pythonpath = ["src"]`).
- Work in an isolated Git worktree (not on `master`). Include the PLACE-4 specs on the branch if still uncommitted.

```python
"""PLACE-4: Cloud Passport keys do not belong in ParameterSets."""

from __future__ import annotations

from pathlib import Path

from ..model import Category, Finding, Layer, Location, ParamsetFile, RepoIndex, Severity
from ..passport import TABLE
from ..rulemeta import RULES
from ..yamlio import LoadedYaml, YamlReadError, leaves, load

_MESSAGE = "{key} is a Cloud Passport contract key; do not store it in a ParameterSet."
_HINT = (
    "Move {key} to the cluster cloud-passport, or to this environment's "
    "cloud-passport if the value is an override."
)


def check(index: RepoIndex) -> list[Finding]:
    bound = _bound_stems(index)
    seen: set[Path] = set()
    findings: list[Finding] = []
    for file in _paramsets(index):
        if file.stem not in bound:
            continue
        resolved = file.path.resolve()
        if resolved in seen:
            continue
        seen.add(resolved)
        loaded = _document(file)
        if loaded is None:
            continue
        params = loaded.doc.get("parameters") if isinstance(loaded.doc, dict) else None
        if not isinstance(params, dict):
            continue
        found: set[str] = set()
        for path, _value in leaves(params):
            if not path:
                continue
            key = str(path[0])
            if key not in TABLE or key in found:
                continue
            found.add(key)
            line, column = loaded.position(("parameters", key))
            findings.append(_finding(file, key, line, column))
    findings.sort(key=lambda item: (item.path.as_posix(), item.key, item.line))
    return findings


def _document(file: ParamsetFile) -> LoadedYaml | None:
    if file.loaded is not None:
        return file.loaded
    if file.is_jinja:
        try:
            return load(file.path)
        except YamlReadError:
            return None
    return None


def _bound_stems(index: RepoIndex) -> set[str]:
    found: set[str] = set()
    for env in index.environments:
        for category in Category:
            for names in env.bound_targets(category).values():
                found.update(names)
    return found


def _scope(file: ParamsetFile) -> str:
    if file.layer is Layer.REPOSITORY:
        return "repository"
    if file.cluster and file.env:
        return f"{file.cluster}/{file.env}"
    if file.cluster:
        return file.cluster
    return "repository"


def _finding(file: ParamsetFile, key: str, line: int, column: int) -> Finding:
    meta = RULES["PLACE-4"]
    return Finding(
        rule="PLACE-4",
        severity=Severity.WARNING,
        path=file.path,
        line=line,
        column=column,
        issue_type=meta.default_issue_type,
        action=meta.default_action,
        key=key,
        scope=_scope(file),
        message=_MESSAGE.format(key=key),
        hint=_HINT.format(key=key),
        related=(),
        locations=(Location(file.path, line, column),),
    )


def _paramsets(index: RepoIndex) -> list[ParamsetFile]:
    out = list(index.site_paramsets)
    for cluster in index.clusters.values():
        out.extend(cluster.paramsets)
        for env in cluster.environments:
            out.extend(env.paramsets)
    return out
```

```python
"""PLACE-3: place by the system tier (SHOULD). See docs/algorithms/place3.md."""

from __future__ import annotations

from ..effective import EnvEffective
from ..model import Finding, PassportFile, RepoIndex, Severity
from ..passport import Catalogs
from ..rulemeta import RULES


def check(
    index: RepoIndex,
    full: dict[str, EnvEffective],
    lower: dict[str, EnvEffective],
    site: dict[str, EnvEffective],
    catalogs: Catalogs,
) -> list[Finding]:
    del full, lower, site, catalogs
    return _misplaced_files(index)


def _file_hint(index: RepoIndex, item: PassportFile) -> str:
    if item.cluster:
        return f"Move it to environments/{item.cluster}/cloud-passport/"
    if len(index.clusters) == 1:
        name = next(iter(index.clusters))
        return f"Move it to environments/{name}/cloud-passport/"
    return "Move it to a cluster's cloud-passport/"


def _misplaced_files(index: RepoIndex) -> list[Finding]:
    findings: list[Finding] = []
    for item in index.passports:
        if item.on_cluster:
            continue
        meta = RULES["PLACE-3"]
        findings.append(
            Finding(
                rule="PLACE-3",
                severity=Severity.WARNING,
                path=item.path,
                line=1,
                column=1,
                issue_type=meta.default_issue_type,
                action=meta.default_action,
                key=item.stem,
                scope=item.cluster or "repository",
                message=f"Passport {item.stem} is not at the cluster layer.",
                hint=_file_hint(index, item),
```

```markdown
Russian copy (for the reader): [`ru/place4.md`](./ru/place4.md).

## 1. Standard sentence

**PLACE-4 (SHOULD):** a Cloud Passport **contract** key does not live in a
ParameterSet. Override it in that environment's cloud-passport, not in a
paramset. This cycle **reports** the key and tells the reader to move it. It
does **not** edit files. Severity is `warning`.

## 2. What is checked

Input: `RepoIndex` only. Do not call `compute`. Keys come from `TABLE` in
`passport.py` (do not union flattened passport-file keys).

A ParameterSet file is in scope iff its `stem` appears in at least one
environment's `envSpecific*` lists (`env.bindings`). Site, cluster, and
environment layers all count. Deduplicate by resolved path.

Unbound files are silent. A contract key that exists only in
`cloud-passport/passport.yml` is silent.

## 3. Jinja

If `file.is_jinja` or `file.loaded` is missing, try `load(file.path)`.
Success → scan that doc. `YamlReadError` → skip (no finding). Do not change
discovery.

Error / unloadable non-jinja files: skip.

## 4. What to scan

`leaves` of the `parameters` map. A leaf's **top key** is `path[0]`. If that
string is in `TABLE`, one finding for that file + top key. Nested children of
the same top key do not add a second finding.

## 5. Finding

Sort findings by `(path.as_posix(), key, line)`.
```
