> Use `superpowers:executing-plans` to implement this plan in the current branch with test-driven development.

**Architecture:** Share safe template source discovery and Jinja parsing. Keep presence analysis and complexity

## Constraints and review focus

- Keep all TPL-4 findings Information / Review.
- Allow recognizable Helm raw blocks and review other raw blocks.
- Never render, compile, or load a template dependency.
- Keep private repository data and development files out of distribution archives.
- Preserve TPL-1 descriptor exceptions, including its non-rendered namespace selector exception.

Review alias safety, expression evaluation order, lexical variable scope, raw delimiters in comments,
and scalar boundaries in YAML descriptors. Tests in Tasks 1 and 2 cover these cases.
