# PLACE-8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Report empty entities without visible bindings for manual review.

**Architecture:** Extend discovery and the existing index with profiles, credentials, and their bindings. Resolve physical paths using existing ParameterSet staging and ordered profile/credential buckets; inspect structure in a dedicated PLACE-8 rule.

**Tech Stack:** Python 3.12, ruamel.yaml, pytest, existing Click CLI.

**Spec:** `docs/superpowers/specs/2026-09-11-place8-design.md` (binding authority).

## Global Constraints

- Implement only the agreed empty-entity part; no size, service-name, or concern heuristics.
- Empty bound entities and nonempty entities produce no finding. Empty unbound entities produce Information / Review.
- Template bindings are not checked. Exact finding text and all discovery/resolution details are defined by the spec.
- Keep existing constructors compatible with default-empty fields; no new dependencies or CLI flags.
- Use synthetic test data only. No network, upload, generation, or modifications in real repositories.
- Work locally on the existing `feat/place8` branch; preserve unrelated untracked files. Controller handles any Git staging/commits.
