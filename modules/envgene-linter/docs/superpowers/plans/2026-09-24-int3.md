**Goal:** Report used reference names defined at multiple scopes under INT-3.

**Architecture:** Add one rule beside INT-2. Reuse the index and connections to establish consumers,
then enumerate matching definitions across the consumer's scopes without changing shared resolution.

**Tech stack:** Python 3.12, pytest, Click, and ruamel.yaml.

**Spec:** [INT-3 specification and design](/modules/envgene-linter/docs/superpowers/specs/2026-09-24-int3-design.md).

Paths below are relative to `modules/envgene-linter` unless they start with `/`.
The user approved this plan and inline execution. Read the full specification before changing the implementation.

## Global constraints

- Require Python 3.12 or newer. Add no runtime dependencies.
- Run locally without rendering templates, decrypting credentials, or making network calls.
- Preserve the behavior and findings of existing rules.
- Enable INT-3 by default after INT-2 and before NAME-1.
- Emit Warning / Fix for confirmed definitions at two or more scopes.
- Keep CLI findings nonfatal, with exit code 0 and the existing report behavior.
- Never include document values, Credential IDs, or source expressions in INT-3 finding text.
- Keep file access inside the repository and outside `.git`. Do not traverse directory symlinks.

Development dependency installation is separate from the runtime network prohibition.
The available system Python failed test collection because `ruamel.yaml` was absent during initial exploration.
Use a dedicated environment and install the declared development dependencies before interpreting test failures.

## Review focus

- Shared Template Variable fallback scans Inventory recursively. One file must not become two candidates.
- Physical aliases can cross scopes. One physical definition must not become a conflict.
- Different extensions share a reference stem. Cross-scope detection must not compare full filenames only.
- Malformed YAML still occupies a filename. Content parsing must not erase a confirmed conflict.
- Shared files can serve several environments. Deduplication must retain each environment's lookup context.
