# NAME-1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Report NAME-1 when different paramset key names share one non-empty string; TYPE Information, ACTION Review; never autofix.

**Architecture:** `rules/name1.py` walks every `ParamsetFile` on the index (no Effective Set). Leaves of `parameters` and `applications[].parameters` group by string value. The catalog, `RULE_ORDER`, and engine grow by one rule. Console and HTML already render unknown-or-ordered rules; they pick up NAME-1 via `RULE_ORDER`.

**Tech Stack:** Python 3.12+, pytest, existing `yamlio.leaves` / `dotted` / `LoadedYaml.position`.

**Spec (English):** `docs/superpowers/specs/2026-09-05-name1-design.md`  
**Spec (Russian):** `docs/superpowers/specs/ru/2026-09-05-name1-design.md`

## Global Constraints

- Warn only. ACTION is Review. Do not collapse keys or invent autofix.
- No length minimum. Compare non-empty strings only (ignore `""`, int, bool, null).
- Do not scan env_definition, Cloud Passport, or non-paramset YAML.
- Do not call `compute` / Effective Set for NAME-1.
- Distinct **key names** (full dotted path). Same name in many files is not NAME-1.
- Drop `_USER`/`_USERNAME` + `_PASSWORD`/`_PASS` pairs that share the value (last dotted segment, case-insensitive).
- `Severity.INFORMATION = "information"`. PLACE-* stay `WARNING`.
- `RULE_ORDER = ("PLACE-1", "PLACE-2", "PLACE-3", "NAME-1")`.
- Catalog description: `Different keys may name the same concept`.
- Hint text (exact): `Review whether they mean the same concept for the same consumer. Do not collapse them unless that is intended.`
- Message: `Keys {sorted names}, … share the value {value!r}.`
- Prefer `.venv/bin/python -m pytest`.
- Write `docs/algorithms/name1.md` and `docs/algorithms/ru/name1.md`.

### Task 2: NAME-1 rule

**Files:**

- Create: `src/envgene_linter/rules/name1.py`
- Create: `tests/test_name1.py`

**Interfaces:**

- Consumes: `RepoIndex`, `ParamsetFile.parameters` / `.applications`, `leaves`, `dotted`, `loaded.position`, `RULES["NAME-1"]`, `Location`
- Produces: `def check(index: RepoIndex) -> list[Finding]`

Walk paramsets:

```python
def _paramsets(index: RepoIndex) -> list[ParamsetFile]:
    out = list(index.site_paramsets)
    for cluster in index.clusters.values():
        out.extend(cluster.paramsets)
        for env in cluster.environments:
            out.extend(env.paramsets)
    return out
```

Skip `is_jinja` or `error` or `loaded is None`.

Collect hits: for `parameters`, `yaml_path = ("parameters", *leaf)`; name = `dotted(leaf)`. For each application `(index, app_name, params)`, `yaml_path = ("applications", index, "parameters", *leaf)`; name = `f"{app_name}.{dotted(leaf)}"`. Keep leaf value only if `isinstance(value, str) and value != ""`.

Position: `file.loaded.position(yaml_path)`.

Group by value. For each group: unique names; `_drop_cred_pairs`; if `len(names) < 2` skip.

Sort hits by `(path.as_posix(), key)`. First hit is primary.

Finding fields exactly as the spec table. `related=tuple(sorted(names))`. `message=f"Keys {', '.join(sorted(names))} share the value {value!r}."` `locations=tuple(Location(h.path, h.line, h.column) for h in sorted_hits)` (keep duplicate files if two keys in one file — two locations).

Credential helper (last segment, case-insensitive), pairs:

```python
_PAIRS = (
    ("_USER", "_PASSWORD"),
    ("_USERNAME", "_PASSWORD"),
    ("_USER", "_PASS"),
    ("_USERNAME", "_PASS"),
)
```

A name is dropped if its last segment `S` and some other remaining name’s last segment `T` form one of those suffix pairs with the same stem (the old-linter logic: if `S.endswith(left)` look for `S[:-len(left)]+right` as another last-segment).

```python
from envgene_linter.discovery import build_index
from envgene_linter.model import Action, IssueType, Severity
from envgene_linter.rules.name1 import check


def _name1(repo):
    return check(build_index(repo.root))


def test_three_kafka_keys_one_value(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset(
        "cluster-01",
        "env-01",
        "cloud-deploy",
        {
            "KAFKA_URL": "kafka.internal:9092",
            "BOOTSTRAP_SERVERS": "kafka.internal:9092",
            "STREAMING_BROKER_ADDRESS": "kafka.internal:9092",
        },
    )
    findings = _name1(repo)
    assert len(findings) == 1
    item = findings[0]
    assert item.rule == "NAME-1"
    assert item.severity is Severity.INFORMATION
    assert item.issue_type is IssueType.INFORMATION
    assert item.action is Action.REVIEW
    assert set(item.related) == {"BOOTSTRAP_SERVERS", "KAFKA_URL", "STREAMING_BROKER_ADDRESS"}
    assert len(item.locations) == 3
    assert item.message == (
        "Keys BOOTSTRAP_SERVERS, KAFKA_URL, STREAMING_BROKER_ADDRESS share the value "
        "'kafka.internal:9092'."
    )
    assert item.hint == (
        "Review whether they mean the same concept for the same consumer. "
        "Do not collapse them unless that is intended."
    )


def test_nested_map_is_a_distinct_key(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    path = (
        repo.root / "environments/cluster-01/env-01/Inventory/parameters/cloud-deploy.yml"
    )
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(
        "name: cloud-deploy\n"
        "parameters:\n"
        "  BOOTSTRAP_SERVERS: kafka.internal:9092\n"
        "  outer:\n"
        "    KAFKA_URL: kafka.internal:9092\n",
        encoding="utf-8",
    )
    findings = _name1(repo)
    assert len(findings) == 1
    assert set(findings[0].related) == {"BOOTSTRAP_SERVERS", "outer.KAFKA_URL"}


def test_same_key_in_two_files_is_silent(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["a"]})
    repo.env("cluster-01", "env-02", deploy={"cloud": ["b"]})
    repo.env_paramset("cluster-01", "env-01", "a", {"KAFKA_URL": "kafka.internal:9092"})
    repo.env_paramset("cluster-01", "env-02", "b", {"KAFKA_URL": "kafka.internal:9092"})
    assert _name1(repo) == []


def test_username_password_placeholder_is_silent(repo):

    repo.env_paramset(
```
