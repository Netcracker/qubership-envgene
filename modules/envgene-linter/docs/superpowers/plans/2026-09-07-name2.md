# NAME-2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Report NAME-2 when a ParameterSet or named definition file's `name` does not equal its filename stem, or has no usable `name`; mismatch is Warning / Fix, missing name is Information / Review; never autofix.

**Architecture:** Discovery adds `NamedEntityFile` rows from five instance-root directories. `rules/name2.py` compares `paramset_stem` to root-document `name` on every paramset and named entity (no Effective Set). Catalog, `RULE_ORDER`, and engine grow by one rule. Console and HTML pick up NAME-2 via `RULE_ORDER`.

**Tech Stack:** Python 3.12+, pytest, existing `paramset_stem` / `LoadedYaml.position` / `RepoBuilder`.

**Spec (English):** `docs/superpowers/specs/2026-09-07-name2-design.md`  
**Spec (Russian):** `docs/superpowers/specs/ru/2026-09-07-name2-design.md`

## Global Constraints

- Do not edit YAML or rename files. Hint only: set `name` to the stem.
- Do not call `compute` / Effective Set for NAME-2.
- Do not scan env_definition, Cloud Passport, credentials, resource profiles, STV, or other YAML.
- ParameterSets: all layers, including orphans. Skip Jinja and load errors.
- Named definitions: only the five directories below; skip Jinja and load errors; dedupe by resolved path.
- Stem = `paramset_stem`. No name = key absent, `None`, or `""`. Else compare `str(name)` to the stem.
- Mismatch: `Severity.WARNING`, TYPE Warning, ACTION Fix.
- Missing name: `Severity.INFORMATION`, TYPE Information, ACTION Review.
- Catalog default: Warning / Fix. Description: `Filename stem must equal the name field`.
- Mismatch message: `{kind} filename stem {stem!r} does not equal the name field {declared!r}.`
- Mismatch hint: `Set name: {stem} to match the filename, which is the reference key.`
- Missing message: `{kind} {filename} has no name field; EnvGene requires it to equal the filename stem {stem!r}.`
- Missing hint: `Set name: {stem}`
- `kind` is `ParameterSet`, `Application definition`, `Registry definition`, or `Artifact definition`.
- `RULE_ORDER = ("PLACE-1", "PLACE-2", "PLACE-3", "NAME-1", "NAME-2")`.
- Prefer `.venv/bin/python -m pytest`.
- Write `docs/algorithms/name2.md` and `docs/algorithms/ru/name2.md`.

`NamedEntityFile` (in `model.py`, next to `PassportFile`):

```python
@dataclass
class NamedEntityFile:
    path: Path
    stem: str
    kind: str
    is_jinja: bool = False
    loaded: LoadedYaml | None = None
    error: str | None = None
```

`RepoIndex` gains `named_entities: list[NamedEntityFile] = field(default_factory=list)`.

`discovery.py` constants and loader (non-recursive, reuse `_yaml_files`):

```python
NAMED_ENTITY_DIRS = (
    ("appdefs", "Application definition"),
    ("configuration/appdefs", "Application definition"),
    ("regdefs", "Registry definition"),
    ("configuration/regdefs", "Registry definition"),
    ("configuration/artifact_definitions", "Artifact definition"),
)


def _load_named_entities(root: Path, skipped: list[str]) -> list[NamedEntityFile]:
    files: list[NamedEntityFile] = []
    seen: set[Path] = set()
    for relative, kind in NAMED_ENTITY_DIRS:
        for path in _yaml_files(root / relative):
            resolved = path.resolve()
            if resolved in seen:
                continue
            seen.add(resolved)
            stem = paramset_stem(path)
            if _is_jinja(path):
                skipped.append(f"{path}: jinja named entity skipped")
                files.append(NamedEntityFile(path=path, stem=stem, kind=kind, is_jinja=True))
                continue
            try:
                loaded = load(path)
            except YamlReadError as exc:
                skipped.append(str(exc))
                files.append(NamedEntityFile(path=path, stem=stem, kind=kind, error=str(exc)))
                continue
            files.append(NamedEntityFile(path=path, stem=stem, kind=kind, loaded=loaded))
    return files
```

Call it from `build_index` after the `environments/` check and pass `named_entities=_load_named_entities(root, skipped)` into `RepoIndex`. Import `NamedEntityFile`.

Do not import `compute` in `name2.py`.

Walk paramsets the same way as NAME-1 (`site_paramsets`, then each cluster's paramsets and each env's paramsets). Then walk `index.named_entities`.

For each file: skip `is_jinja` or `error` or `loaded is None`. Read root `name`:

- key absent or value is `None` or `""` → missing-name finding (Information / Review). Position: `loaded.position(("name",))` if the key exists, else `(1, 1)`.
- else `declared = str(value)`; if `declared == stem` skip; else mismatch (Warning / Fix) at `loaded.position(("name",))`.

One finding per file. `key="name"`, `scope=stem`, `related=()`, `locations` one `Location`. `{filename}` is `path.name`. `{kind}` is `"ParameterSet"` or `entity.kind`.

Mismatch uses `Severity.WARNING` and catalog default TYPE/ACTION. Missing uses `Severity.INFORMATION`, `IssueType.INFORMATION`, `Action.REVIEW`.

from envgene_linter.discovery import build_index
from envgene_linter.model import Action, IssueType, Severity
from envgene_linter.rules.name2 import check


def _name2(repo):
    return check(build_index(repo.root))


def test_matching_paramset_name_is_silent(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset("cluster-01", "env-01", "cloud-deploy", {"LOG_LEVEL": "info"})
    assert _name2(repo) == []


def test_mismatch_paramset_is_warning_fix(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    path = (
        repo.root / "environments/cluster-01/env-01/Inventory/parameters/cloud-deploy.yml"
    )
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(
        "name: deploy-params\nparameters:\n  LOG_LEVEL: info\n",
        encoding="utf-8",
    )
    findings = _name2(repo)
    assert len(findings) == 1
    item = findings[0]
    assert item.rule == "NAME-2"
    assert item.severity is Severity.WARNING
    assert item.issue_type is IssueType.WARNING
    assert item.action is Action.FIX
    assert item.key == "name"
    assert item.scope == "cloud-deploy"
    assert item.message == (
        "ParameterSet filename stem 'cloud-deploy' does not equal the name field "
        "'deploy-params'."
    )
    assert item.hint == (
        "Set name: cloud-deploy to match the filename, which is the reference key."
    )
    assert len(item.locations) == 1


def test_missing_paramset_name_is_information(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
