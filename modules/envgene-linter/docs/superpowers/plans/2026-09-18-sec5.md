# SEC-5 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Track progress below.

**Goal:** Review protection of connected secrets with Information / Review findings.

**Architecture:** Add a separate security-source resolver alongside the existing Connections model, retaining source kind and environment. A pure value classifier recognizes SOPS and supported reference forms; SEC-5 follows references in the correct catalog and emits redacted findings. Existing rules keep their current source sets.

**Tech Stack:** Python 3.12+, ruamel.yaml, pytest; no new dependencies.

**Spec:** [Approved design](../specs/2026-09-18-sec5-design.md).

## Global constraints

- Information / Review for every SEC-5 finding.
- Connected inputs only; safe repository paths; no network, decryption, environment-secret lookup or corpus mutation.
- Report no values, identifiers, variable names or source expressions.
- Preserve current rule behavior and CLI exit status.
- Work in the current feature checkout: its uncommitted SEC-1/3/4 implementations are prerequisites. Do not move, discard or commit unrelated changes.

## Task 1: Expand security source selection

Files: create `src/envgene_linter/security_sources.py` and `tests/test_security_sources.py`.

Interfaces: `collect_security_sources(index, connections) -> SecurityInputs`; dataclasses `SecuritySource(path, kind, environment)`, `SecurityBag(path, prefix, environment, catalog, fields=None)`, `SecurityIssue(path, prefix=())`. `SecurityInputs` has `sources`, `bags`, `issues` lists. `sources` are whole-file inputs; `bags` hold consumer parameter locations, with `fields=None` for name-based detection and an explicit field tuple for system consumers. Catalogs identify the exact file to resolve references against; selected system catalog entries are inspected only when referenced.

- [x] Add selection tests before implementation: fixed environment source, passport priority, deployer binding/precedence/fallback, system integration and active registry consumers, unsafe first-priority paths, and unchanged legacy Connections sets.
- [x] Run `.venv/bin/python -m pytest tests/test_security_sources.py -q`; confirm missing feature failures.
- [x] Implement local-only selection following the approved spec and generator lookup order. Record unresolvable known consumers as generic SecurityIssue values. Do not populate legacy credential sets with new source kinds.
- [x] Run source tests; review source selection against the spec.

Selection assertion example:
```python
inputs = collect_security_sources(index, connections)
assert {source.path for source in inputs.sources} == {expected_generated, expected_passport}
assert connections.credentials == old_credentials
```

## Task 2: Classify values and emit SEC-5 findings

Files: create `src/envgene_linter/security_values.py`, `src/envgene_linter/rules/sec5.py`, `tests/test_sec5.py`.

Interfaces: rule `check(index, connections=None) -> list[Finding]`; source resolver from Task 1. Classifier returns protected, literal, unsupported-encryption, unknown or a parsed reference, never evaluates expressions. Reference resolution uses catalog path + entry + property and cycle detection.

- [x] Write parameterized tests for plaintext, valid SOPS marker with metadata, missing metadata, malformed token, Fernet, unknown expression, valid/invalid external entries, empty values and composite strings.
- [x] Confirm failures using `.venv/bin/python -m pytest tests/test_sec5.py -q`.
- [x] Implement SOPS structural checks (AES256_GCM token fields, metadata mapping with encrypted mac and key-recipient metadata; no crypto verification). Traverse Credential data and selected parameter bags with alias guards.
- [x] Resolve complete literal-ID local and external references. Inspect selected target entries; unknown/ambiguous/missing targets and cycles receive Review at consumer locations. Deduplicate physical findings; no raw keys or values in messages.
- [x] Test reference contexts, nested/app params, encrypted type, unreadable/Jinja inputs, source precedence, CI fallback overrides and report redaction.

Finding assertions:
```python
assert (finding.issue_type.value, finding.action.value) == ('Information', 'Review')
assert secret_value not in repr(findings)
assert credential_id not in repr(findings)
```
