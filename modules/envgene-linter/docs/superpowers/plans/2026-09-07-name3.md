# NAME-3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Report NAME-3 when a cluster, environment, or namespace directory name, or an indexed YAML stem, is not kebab-case; TYPE Warning, ACTION Fix; never rename files.

**Architecture:** `rules/name3.py` walks names already on `RepoIndex` (clusters, envs, paramsets, named entities, passports) and lists direct children of each env's `Namespaces/` directory. No discovery change. Catalog, `RULE_ORDER`, and engine grow by one rule.

**Tech Stack:** Python 3.12+, pytest, existing `RepoIndex` / `RepoBuilder`.

**Spec (English):** `docs/superpowers/specs/2026-09-07-name3-design.md`  
**Spec (Russian):** `docs/superpowers/specs/ru/2026-09-07-name3-design.md`

## Global Constraints

- Do not rename files or directories. Hint only: kebab-case rename.
- Do not call `compute` / Effective Set for NAME-3.
- Do not check YAML keys or enum values.
- Do not scan credentials, STV, or resource profiles (not on the index).
- Kebab-case: full match `^[a-z0-9]+(?:-[a-z0-9]+)*$`.
- Skip-list: `Inventory`, `Namespaces`, `parameters`, `env_definition`, `credentials`, `Credentials`, `resource_profiles`, `rp_override`, `Profiles`, `configuration`, `configurations`, `shared-template-variables`, `shared_template_variables`, `cloud-passport`, `cloud-passports`, `app-deployer`, `cloud-deployer`.
- Warning / Fix. Message: `{kind} {name!r} is not kebab-case.` Hint: `Rename to kebab-case (lowercase tokens separated by hyphens).`
- Do not call `str.capitalize()` on `kind`.
- Catalog description: `Filenames, directories, and namespaces use kebab-case`.
- `RULE_ORDER = ("PLACE-1", "PLACE-2", "PLACE-3", "NAME-1", "NAME-2", "NAME-3")`.
- Prefer `.venv/bin/python -m pytest`.
- Write `docs/algorithms/name3.md` and `docs/algorithms/ru/name3.md`.

### Task 2: NAME-3 rule

**Files:**

- Create: `src/envgene_linter/rules/name3.py`
- Create: `tests/test_name3.py`

**Interfaces:**

- Consumes: `RepoIndex` clusters/envs/paramsets/named_entities/passports, `RULES["NAME-3"]`, `Location`
- Produces: `def check(index: RepoIndex) -> list[Finding]`

Do not import `compute`. Do not change discovery.

```python
import re

_KEBAB = re.compile(r"^[a-z0-9]+(?:-[a-z0-9]+)*$")
_SKIP = frozenset({
    "Inventory",
    "Namespaces",
    "parameters",
    "env_definition",
    "credentials",
    "Credentials",
    "resource_profiles",
    "rp_override",
    "Profiles",
    "configuration",
    "configurations",
    "shared-template-variables",
    "shared_template_variables",
    "cloud-passport",
    "cloud-passports",
    "app-deployer",
    "cloud-deployer",
})
_HINT = "Rename to kebab-case (lowercase tokens separated by hyphens)."
```

Walk: each cluster name (`Cluster directory`, `cluster.path`); each env name (`Environment directory`, `env.path`); each non-hidden child directory of `env.path / "Namespaces"` (`Namespace`); every paramset including Jinja (`ParameterSet`, `_paramsets` like NAME-1); every named entity (`entity.kind`); every passport (`Cloud Passport`).

For each name: if in `_SKIP` or `_KEBAB.fullmatch(name)` → skip. Else one finding: Warning, catalog TYPE/ACTION, `key=name`, `scope=kind`, line/column `1`, `locations` one `Location`, message `f"{kind} {name!r} is not kebab-case."`, hint `_HINT`. Do not `capitalize` kind.

Sort findings by `(path.as_posix(), key, line)`.

- [ ] **Step 1: Write `tests/test_name3.py`**

```python
from envgene_linter.discovery import build_index
from envgene_linter.model import Action, IssueType, Severity
from envgene_linter.rules.name3 import check


def _name3(repo):
    return check(build_index(repo.root))


def test_cluster_not_kebab(repo):
    repo.env("Cluster_01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset("Cluster_01", "env-01", "cloud-deploy", {"LOG_LEVEL": "info"})
    findings = [item for item in _name3(repo) if item.key == "Cluster_01"]
    assert len(findings) == 1
    item = findings[0]
    assert item.rule == "NAME-3"
    assert item.severity is Severity.WARNING
    assert item.issue_type is IssueType.WARNING
    assert item.action is Action.FIX
    assert item.message == "Cluster directory 'Cluster_01' is not kebab-case."
    assert item.hint == "Rename to kebab-case (lowercase tokens separated by hyphens)."
    assert item.scope == "Cluster directory"


def test_kebab_cluster_and_env_are_silent(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset("cluster-01", "env-01", "cloud-deploy", {"LOG_LEVEL": "info"})
    assert _name3(repo) == []


def test_env_not_kebab(repo):
    repo.env("cluster-01", "Env_01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset("cluster-01", "Env_01", "cloud-deploy", {"LOG_LEVEL": "info"})
    findings = [item for item in _name3(repo) if item.key == "Env_01"]
    assert len(findings) == 1
    assert findings[0].message == "Environment directory 'Env_01' is not kebab-case."


def test_namespace_not_kebab(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset("cluster-01", "env-01", "cloud-deploy", {"LOG_LEVEL": "info"})
    path = repo.root / "environments/cluster-01/env-01/Namespaces/Foo"
    path.mkdir(parents=True)
    findings = [item for item in _name3(repo) if item.key == "Foo"]
    assert len(findings) == 1
    assert findings[0].message == "Namespace 'Foo' is not kebab-case."


def test_paramset_stem_not_kebab(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["Cloud_Deploy"]})
    repo.env_paramset("cluster-01", "env-01", "Cloud_Deploy", {"LOG_LEVEL": "info"})
    findings = [item for item in _name3(repo) if item.key == "Cloud_Deploy"]
    assert len(findings) == 1
    assert findings[0].message == "ParameterSet 'Cloud_Deploy' is not kebab-case."


def test_env_definition_is_not_reported(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset("cluster-01", "env-01", "cloud-deploy", {"LOG_LEVEL": "info"})
    assert all(item.key != "env_definition" for item in _name3(repo))


def test_inventory_dir_is_not_reported(repo):
    repo.env("cluster-01", "env-01", deploy={"cloud": ["cloud-deploy"]})
    repo.env_paramset("cluster-01", "env-01", "cloud-deploy", {"LOG_LEVEL": "info"})
    assert all(item.key != "Inventory" for item in _name3(repo))
```
